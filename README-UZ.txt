HISOBIM — Android ilovasi

Ilova imkoniyatlari:
- 4 xonali PIN-kod bilan kirish
- Daromad va xarajat kiritish
- Balansni avtomatik hisoblash
- Kirim-chiqim tarixi
- Umumiy statistika
- Ma'lumotlarni telefonda saqlash (internet talab qilmaydi)

APK yaratish:
1. Ushbu ZIP faylni GitHub hisobingizdagi yangi repositoryga yuklang.
2. Actions bo‘limini oching.
3. Build HISOBIM APK jarayonini ishga tushiring (yoki fayllar main branchga yuklangach avtomatik ishlaydi).
4. Jarayon tugagach HISOBIM-APK artifactini yuklab oling.
5. Yuklangan ZIP ichidagi app-debug.apk faylini Android telefonga o‘rnating.

Eslatma: bu manba loyiha; APK hali qurilmagan va real telefonda sinovdan o‘tkazilmagan.
PIN-kodni unutmang. Ilova ma'lumotlari telefon xotirasida saqlanadi.
